# 06 · 国际化

## 1. 目录

```
src/locales/
├─ index.tsx        # LocaleProvider、useLocale、语言持久化
├─ types.ts         # LocaleCode / Translate / MessageVars
├─ antd.ts          # 业务语言 → antd 语言包映射
├─ dayjs.ts         # 业务语言 → dayjs 全局语言（日期面板的月份/星期）
└─ messages/
   ├─ zh-CN.ts      # 源语言字典（新增文案先写这里）
   ├─ en-US.ts      # 英文字典（类型强制覆盖全部 key）
   └─ index.ts
```

## 2. 在组件中使用

```tsx
import { useLocale } from '../../locales';

const Demo: React.FC = () => {
  const { t, locale, setLocale, availableLocales } = useLocale();
  return <span>{t('nav.home')}</span>;
};
```

插值：

```tsx
t('deepseek.statusTip', { status: statusText });   // 服务状态：已就绪
```

## 3. antd 组件文案联动

`app/AppProviders.tsx` 中：

```tsx
<LocaleProvider>
  <ConfigProvider locale={ANTD_LOCALES[locale]} componentSize="middle">
```

因此分页、空状态、表单校验提示等 antd 内置文案会随语言切换。
新增语言时只需在 `locales/antd.ts` 补一条映射。

## 3.1 日期控件的语言

日期面板（`DatePicker` / `RangePicker` / `Calendar`）的月份、星期、周起始取自 **dayjs 的全局 locale**，
与上面的 antd 语言包是两套独立配置，只配 `ConfigProvider` 会出现"按钮中文、月份英文"的混排。

`locales/dayjs.ts` 负责同步：`LocaleProvider` 在初始化与切换语言时调用 `applyDayjsLocale()`，
内部传入语言包对象（而非字符串），同时完成注册与全局切换，避免副作用 import 被 tree-shaking 移除。

```ts
dayjs.locale(zhCnLocale);   // 注册 + 切换，不写成 import 'dayjs/locale/zh-cn'
```

## 4. 切换入口

顶部导航右侧的语言选择器（`AppNav`），选择结果持久化在 `localStorage`（key：`app.locale`），
刷新后保持。

## 5. 新增文案步骤

1. 在 `src/locales/messages/zh-CN.ts` 增加 key（扁平结构，点号表层级，如 `deepseek.input.stop`）；
2. 在 `en-US.ts` 补同名 key——漏补会直接编译报错（`Record<MessageKey, string>` 约束）；
3. 组件内改用 `t('key')`，删除硬编码文案。

## 6. 新增语言步骤

1. `locales/types.ts` 的 `LocaleCode` 增加语言码；
2. `locales/messages/` 新增字典文件，并在 `messages/index.ts` 导出；
3. `locales/index.tsx` 的 `DICTIONARIES` 与 `AVAILABLE_LOCALES` 注册；
4. `locales/antd.ts` 补 antd 语言包映射；
5. `locales/dayjs.ts` 的 `DAYJS_LOCALES` 补对应语言包对象。
