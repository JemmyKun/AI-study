
# 智能问答页面 - 打字机流式输出

## 概要

基于现有 CRA + React 19 + TypeScript 项目，开发一个类似 DeepSeek 首页的智能问答界面。采用**前端模拟**方式生成回答内容，重点实现打字机流式输出效果。

## 新增依赖

- `react-markdown` - Markdown 内容渲染
- `react-syntax-highlighter` - 代码块语法高亮
- `@types/react-syntax-highlighter` - 类型定义

## 关键实现

### 1. 打字机效果 Hook (`useTypewriter.ts`)
- 接收完整文本，按字符逐步输出
- 支持配置打字速度（默认 30-50ms/字符）
- 支持中途停止（`abort`）
- 返回 `{ displayedText, isTyping, abort }`

### 2. 页面布局（暗色主题，类 DeepSeek 风格）
- 顶部：标题栏 "AI 助手"
- 中间：对话消息列表区域，自动滚动到底部
- 底部：输入框 + 发送按钮，固定底部
- 用户消息靠右（蓝色气泡），AI 消息靠左（深灰气泡）
- 初始状态显示欢迎语和示例问题

### 3. Markdown 渲染
- AI 回答支持 Markdown 渲染（标题、列表、代码块、表格等）
- 代码块带语法高亮和复制按钮
- 打字机输出过程中实时渲染已输出的 Markdown

### 4. 交互功能
- Enter 发送，Shift+Enter 换行
- 发送中可点击"停止"中断输出
- 消息列表自动滚动到最新消息
- 支持多轮对话（对话历史展示）

### 5. 模拟回答 (`mockResponses.ts`)
- 预设几组问答对，根据关键词匹配返回
- 无匹配时返回通用回答
- 回答内容包含 Markdown 格式（代码块、列表等），以展示渲染效果
